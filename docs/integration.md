# Integration Architecture

This document describes how Member A (Ingestion & UI) and Member B (Retrieval & Generation) integrate.

---

## 1. System Integration Flow

```
[Member A: PDFs]
       │
       ▼
ingest_pdf(path, equipment_model, synthetic)
       │
       ▼ list[Chunk]
[Member B: index_chunks]
       │
       ▼ IndexingSummary
[Qdrant Local Vector Store]
       ▲
       │ retrieve(question, top_k, equipment_model)
[Member B: Local Retrieval + Ollama Generation]
       ▲
       │ answer_question(question, equipment_model)
       │ answer_with_image(question, image_path, equipment_model)
       │
[Member A: Streamlit UI]
```

---

## 2. Shared Data Contracts (`contracts.py`)

All cross-module interaction passes through immutable data structures:
* `Chunk`: Generated by Member A, consumed by Member B's `index_chunks()`.
* `IndexingSummary`: Returned by Member B to summarize indexing progress, duplicates, and failures.
* `Evidence`: Ranked chunks returned by Member B's `retrieve()`.
* `Answer`: Returned by Member B's `answer_question()` and `answer_with_image()`. Member A's UI renders:
  - `Answer.text`: Main text with bracketed citations (e.g. `[source_id]`).
  - `Answer.evidence`: Supporting evidence drawer/cards.
  - `Answer.insufficient_evidence`: Notice banner if documentary support is lacking.
  - `Answer.observations`: Visual inspection bullet points when image input is provided.

---

## 3. Public Service Facade (`src/services.py`)

To ensure both members can develop and test independently without hard dependencies:
* `create_ingestor(mock=True)`: Allows Member B to test indexing and retrieval without PDF parsing libraries.
* `create_backend(mock=True)`: Allows Member A to develop and demo the Streamlit UI without running Ollama or Qdrant.

---

## 4. Error Handling Contract

| Scenario | Contractual Behavior |
|---|---|
| Blank or whitespace query | Raises `ValueError` |
| Invalid `top_k` (< 1) | Raises `ValueError` |
| Empty vector database | Returns `Answer(text="No indexed documents available.", evidence=[], insufficient_evidence=True)` |
| Equipment mismatch | Returns `Answer(..., insufficient_evidence=True)` |
| Missing local models / Ollama down | Raises `RuntimeError` stating localhost connection failure |
| Corrupt / missing image | Raises `FileNotFoundError` or `ValueError` |
| PDF page with no extractable text | Logged as warning; omitted from returned `list[Chunk]` without error |
| Re-indexing duplicate chunk | Counted in `chunks_skipped` (if identical) or `chunks_indexed` (if metadata updated) |

## 5. Import & Launch Conventions

All imports assume the project root is in `PYTHONPATH`:
```bash
export PYTHONPATH=.
```

**Single Launch Command**:
```bash
streamlit run src/ui/app.py
```
